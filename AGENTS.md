
# EchoVault — Agent Instructions

This project is a SoftUni Capstone application.

Before making any changes, read:
- EchoVault_Project_Blueprint.md
- .github/copilot-instructions.md

Tech stack:
- HTML5, CSS3, Bootstrap 5
- Vanilla JavaScript
- Vite and npm
- Supabase

Do not use React, Vue or TypeScript.

Implement one task at a time.
Do not build the entire project at once.

After each task:
1. Explain the changes made.
2. Run relevant tests.
3. Report any errors.
4. List the modified files.

Do not automatically commit changes to GitHub.
